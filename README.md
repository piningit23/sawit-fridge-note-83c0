One funny passive-aggressive note a smart fridge leaves for its owner: a single line, dry, petty and specific — the fridge counts your door openings, remembers the yogurt you hid behind the pickles, and keeps it cold anyway.

## Run it

```sh
python3 main.py
```

It writes the note to `/output/entry.txt` (129 characters, one line).
